# 新旧插件功能对照表

> dsh-suggestion-chips v0.4.12 → dsh-suggest-flow v0.1.0

## 1. 功能对照

| 能力 | dsh-suggestion-chips | dsh-suggest-flow | 变化 |
|---|---|---|---|
| 建议生成时机 | 回答结束自动 | 回答结束自动 | 一致 |
| 每轮模型调用 | 1 次 | 1 次（refresh 单独计） | 一致 |
| 建议条数 | 1-4 可配（目标=配额） | 1-4 可配（目标=上限，允许 0） | 语义更明确 |
| 输出协议 | 纯字符串数组 | `{t, i}` 对象（字符串兼容降级） | 升级 |
| 建议方向 | 无（prompt 泛泛要求覆盖三类） | **Explore / Expand / Apply 显式三向** + 场景路由表 | 新增 |
| 方向可视化 | 无 | chip 前方向圆点 + 本地化 title | 新增 |
| 方向多样性 | 无结构保证 | 方向轮转选择（本地，零成本） | 新增 |
| 同义改写/回声过滤 | 仅完全重复去重 | 归一化键 + 包含式近重 + 用户回声 + 客套话块名单 + 元列表行 | 升级 |
| 手动刷新 | ❌ | **⟳ 一键换一组**（avoid 集合、6s 冷却、每轮 5 次上限、失败保留原组） | 新增 |
| 刷新去重保证 | — | 本轮已展示全集（含历史被替换组）不再出现 | 新增 |
| 用户偏好记忆 | 采纳/忽略文本进 prompt | 同左 + **方向偏置**（≥3 条带意图采纳、头部 ≥2 且占比 ≥50%） | 升级 |
| 偏好覆盖保护 | 偏好仅为提示 | 偏置措辞 advisory，当前对话需求优先 | 明确 |
| memory.json 兼容 | 自有格式 | 同构格式 + 旧格式条目兼容 + **首次运行只读种子导入** | 继承+迁移 |
| 单击填入 | ✅ | ✅ | 继承 |
| 双击发送（可关） | ✅ 300ms 自管双击窗口 | ✅ 同实现 | 继承 |
| 键盘操作 | ↑激活/←→↑↓二维循环/Enter/Ctrl+Enter/Esc | ✅ 同实现 | 继承 |
| 打字隐藏（可关） | ✅ chip 填入不算打字 | ✅ 同实现 | 继承 |
| 悬停完整文本 | title | title（+圆点方向 title） | 继承 |
| 长文本溢出 | 单行省略 | 单行省略 | 继承 |
| 会话切换清理 | running 翻转判定 + 状态重置 | ✅ 同实现 + refresh 请求随会话中止 | 继承+加固 |
| 超时/降级 | 20s 独立超时，静默降级 | ✅ 同实现（refresh 失败同样静默保留） | 继承 |
| 并发保护 | fan-in 共享 job、并发上限 2 | ✅ 同实现 + force 路径满载时 throw 保旧组 | 继承+加固 |
| 防旧请求覆盖新会话 | request.current 校验 + abort | ✅ 同实现 | 继承 |
| 缓存恢复（重开会话） | cache-only，绝不模型调用 | ✅ 同实现 | 继承 |
| 记忆持久化 | 400 条/30 天滚动，原子写 | ✅ 同实现 + 新字段（shownHistory 等） | 继承 |
| 设置持久化/即时生效 | settings.json + 每回合重读 | ✅ 同实现 | 继承 |
| 设置页 | 启用/条数/双击/打字隐藏/键盘/清空记忆/版本更新 | ✅ 同结构，品牌与仓库指向更换 | 继承 |
| 新增设置项 | — | 无（刷新采用固定合理默认值） | 刻意克制 |
| 国际化 | zh/en 内置字典 + locale 服务探测注册 | ✅ 同机制 + 方向/刷新文案 | 继承 |
| 一键更新 | GitHub Releases + dshmarket API | ✅ 同机制，指向 dsh-suggest-flow 仓库 | 继承 |
| 深浅色主题 | dsw alias CSS 变量 | ✅ 同机制 | 继承 |
| 无障碍 | role/aria/焦点样式 | ✅ 同机制 + 圆点 aria-hidden | 继承 |

## 2. 交互行为差异明细

| 场景 | 原插件 | 新插件 |
|---|---|---|
| 对建议不满意 | 等下一轮 | 点 ⟳ 立即换一组；6s 冷却防连点；同轮最多 5 次 |
| 刷新中再点 | — | 按钮禁用（旋转动画指示进行中） |
| 刷新失败/超时 | — | 原建议原地保留，按钮恢复，无打扰 |
| 刷新返回空组 | — | 视为失败：保留原建议（不隐藏整行） |
| 采纳建议后 | 记录 fill/send 文本 | 同左，且宿主自动补方向标签用于偏置 |
| 输出无方向标注 | — | 正常显示文本，仅无圆点 |

## 3. 非目标（两侧一致，刻意不做）

- 不做 Agent 工作流 / 任务自动执行
- 不做独立的 AI 质量评估模型 / 语义分析引擎
- 不做复杂用户画像（仅采纳/忽略 + 方向计数）
- 不做独立启动入口——始终是 DSH 插件

## 4. 与原插件同装

支持。插件 ID、cordis 节点、RPC 命名空间、存储目录、locale NS、CSS 前缀、设置页导航文案全部隔离（详见[架构文档 §7](architecture.md)）。注意两者同装会各自调用一次辅助模型；建议迁移完成后择一禁用。新插件首次运行会把旧插件的采纳历史一次性只读导入自己的 memory.json。
